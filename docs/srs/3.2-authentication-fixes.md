# Sửa mục 3.2 Authentication cho khớp với dự án

Đối chiếu với: `services/core-api` (AuthService, GoogleAuthService, AuthController, các DTO), `apps/mobile` (login, register, change password, session) và `apps/webgis` (LoginPage, AuthContext, Navbar).

Cách dùng: mỗi mục ghi **Vị trí**, **Hiện tại** (để bạn tìm bằng Ctrl+F) và **Thay bằng** (copy dán đè). Mục ghi **Xóa** thì xóa hẳn dòng hoặc đoạn đó. Những phần không có trong file này là đúng, giữ nguyên.

## 3.2.1 Sign In

**1. Primary Trigger**
- Hiện tại: `The user clicks the "Đăng nhập" button from the WebGIS navigation bar or opens the mobile application without a stored session.`
- Thay bằng:
```
The user opens the WebGIS address or the mobile application without a stored session.
```
- Lý do: WebGIS không có nút "Đăng nhập" trên thanh điều hướng; người chưa đăng nhập bị `ProtectedRoute` chuyển thẳng tới `/login`.

**2. Interface: Remember Me**: **Xóa** dòng `Remember Me: Checkbox allowing users to keep the session stored on the device.`
- Lý do: không có ô "Remember Me" ở cả mobile lẫn WebGIS; phiên luôn được lưu.

**3. Normal Case: Remember Me**
- Hiện tại: `If the user selects Remember Me: The system stores the session token on the device so that the application can start without network connectivity.`
- Thay bằng:
```
After a successful sign in: The client always stores the session token and the user profile on the device (local storage on WebGIS, shared preferences on mobile) so that the application can start without network connectivity. The token expires after 24 hours.
```

**4. Normal Case: citizen**
- Hiện tại: `If the account role is citizen: The mobile application opens the home monitor screen and starts a background profile refresh.`
- Thay bằng:
```
If the account role is citizen: The mobile application opens the home monitor screen and starts a background profile refresh; on WebGIS the citizen is shown the read-only map of approved landslide zones.
```

**5. Abnormal Case: deactivated**
- Hiện tại: `If the account has been deactivated by an administrator: The system denies access and displays the account status message.`
- Thay bằng:
```
If an officer or administrator account signs in on the mobile application: The application rejects the session and displays the message "This application is for citizens only." Staff accounts must use the WebGIS.
```
- Lý do: bảng `users` không có trạng thái khóa hay kích hoạt tài khoản. Mobile chặn mọi role khác citizen (`auth_repository.dart`: "Ứng dụng dành cho người dân").

**6. Abnormal Case**: thêm 1 dòng mới (dán sau dòng "If any required field is empty…"):
```
If the password exceeds 72 bytes: The system returns 400 Bad Request, because BCrypt only processes the first 72 bytes.
```

**7. Table 8. Sign In**
- **Xóa** dòng `5 | Remember Me | Checkbox | …`, rồi đánh lại số cột # (6→5, 7→6, 8→7, 9→8).
- Dòng `Form Title`: cột Default Value đổi `"Đăng nhập GeoSentry"` → `"TerraWatch GeoSentry"`.
- Dòng `Google Sign In Button`: cột Default Value đổi `"Đăng nhập với Google"` → `"Đăng nhập bằng Google"`.
- Dòng `Register Link`: cột Default Value đổi `"Tạo tài khoản"` → `"Chưa có tài khoản? Đăng ký"`.

## 3.2.2 Sign Up

**8. Primary Trigger**
- Hiện tại: `The user clicks the "Tạo tài khoản" button from the Sign In screen of the mobile application.`
- Thay bằng:
```
The user clicks the "Chưa có tài khoản? Đăng ký" link on the Sign In screen of the mobile application.
```

**9. Secondary Trigger**
- Hiện tại: `The system redirects the user to the Sign Up screen when an unauthenticated user attempts to subscribe to an area or submit a field report.`
- Thay bằng:
```
The user clicks "Đăng ký tài khoản công dân" on the WebGIS Sign In page.
```
- Lý do: người chưa đăng nhập chỉ thấy màn Sign In, nên không thể vào màn đăng ký vùng hay gửi báo cáo.

**10. Interface**
- **Xóa** dòng `Confirm Password: Input field where users re-enter their password.`
- Hiện tại: `Sign In Link: Link returning the user to the Sign In screen.`
- Thay bằng:
```
Back Button: App bar button returning the user to the Sign In screen.
```
- Lý do: màn đăng ký trên mobile chỉ có 4 ô (Họ và tên, Email, Số điện thoại, Mật khẩu) và không có liên kết "Đã có tài khoản".

**11. Data**
- `Full Name: Must not be empty and must be between 2 and 100 characters.` → thay bằng:
```
Full Name: Must not be empty and must not exceed 100 characters.
```
- `Email: Must not be empty, must be in a valid email format, and must not already exist in the system.` → thay bằng:
```
Email: Must not be empty, must be in a valid email format, must not exceed 150 characters, and must not already exist in the system. The email is stored in lower case.
```
- `Phone Number: Optional. If provided, it must be in a valid phone number format and is used as the SMS delivery address.` → thay bằng:
```
Phone Number: Optional, at most 20 characters. If provided, it is used as the SMS delivery address.
```
- `Password: Must not be empty and must contain at least 8 characters.` → thay bằng:
```
Password: Must not be empty, must contain at least 8 characters and must not exceed 72 bytes.
```
- **Xóa** dòng `Confirm Password: Must not be empty and must match the Password field.`

**12. Abnormal Cases**
- **Xóa** dòng `If the passwords do not match: The system displays the message "Passwords do not match."`
- Hiện tại: `If any required field is empty: The system displays a validation error message.`
- Thay bằng:
```
If any required field is empty or invalid: The application displays the validation message under the field without calling the server; if the server rejects the data, it returns 400 Bad Request with the message "Invalid request".
```

**13. Table 9. Sign Up**
- Dòng `Form Title`: Default Value `"Tạo tài khoản"` → `"Đăng ký"`.
- **Xóa** dòng `6 | Confirm Password | …`.
- Dòng `Sign Up Button`: Default Value `"Đăng ký"` → `"Tạo tài khoản"`.
- Dòng `8 | Sign In Link | Link | No | No | "Đã có tài khoản" | …` → thay cả dòng bằng:
  `Back Button | Icon Button | No | No | "←" | App bar button returning the user to the Sign In screen.`
- Đánh lại số cột # (1–7).

## 3.2.3 Google Sign In

**14. Primary Trigger**: đổi `"Đăng nhập với Google"` → `"Đăng nhập bằng Google"`.

**15. Secondary Trigger**
- Hiện tại: `The user chooses to register without creating a password after being prompted on the Sign Up screen.`
- Thay bằng:
```
N/A
```
- Lý do: màn Sign Up không có lời nhắc nào dẫn sang đăng nhập Google.

**16. Normal Case: existing account**
- Hiện tại: `If the identity token is valid and an account already exists for the email: The system updates the stored profile attributes and returns a session token for the existing account.`
- Thay bằng:
```
If the identity token is valid and a citizen account already exists for the email: The system returns a session token for the existing account without changing its stored profile.
```
- Lý do: `GoogleAuthService` không cập nhật gì vào tài khoản đã có.

**17. Normal Case: new account** (thêm câu cuối vào dòng "…no account exists for the email…"):
```
The full name is taken from the token, or from the part of the email before "@" when the token has no name, and the account receives a random password hash so that it can only be entered through Google.
```

**18. Abnormal Case**: thêm 1 dòng mới:
```
If the email belongs to an officer or administrator account: The system returns 403 Forbidden with the message "Google sign-in is only available for citizen accounts", so that a Google email cannot be used to enter a staff account.
```

**19. Table 10. Google Sign In**: dòng `Google Sign In Button`, Default Value `"Đăng nhập với Google"` → `"Đăng nhập bằng Google"`.

## 3.2.4 Sign Out

**20. Primary Trigger**
- Hiện tại: `The user clicks the "Đăng xuất" button from the account menu of the WebGIS navigation bar or from the mobile application settings screen.`
- Thay bằng:
```
The user clicks the "Đăng xuất" icon button on the WebGIS navigation bar or the "Đăng xuất" button at the bottom of the mobile Profile screen.
```

**21. Interface**: không có hộp xác nhận. Thay 4 dòng (Sign Out Button, Confirmation Dialog, Confirm Button, Cancel Button) bằng:
```
Sign Out Button: Button that ends the session immediately, without a confirmation dialog.
```

**22. Normal Cases**
- Hiện tại: `If the user confirms sign out: The system clears the stored session token, resets the in-memory security context and redirects the user to the Sign In screen.`
- Thay bằng:
```
If the user clicks Sign Out: The client deletes the stored session token and user profile and returns the user to the Sign In screen. No server call is made, because the JSON Web Token is stateless.
```
- **Xóa** dòng `If the user clicks Cancel: The system closes the confirmation dialog and keeps the current session active.`

**23. Abnormal Cases**: thay cả 3 dòng bằng:
```
If the session token is already expired or invalid: The next protected request returns 401 Unauthorized; the client clears the local session and returns the user to the Sign In screen with the message "Your session has expired. Please sign in again."
Because sign out does not revoke the token on the server: A copied token remains valid until it expires (24 hours). Server-side revocation is not part of the current release.
```

**24. Table 11. Sign Out**: **Xóa** các dòng 2, 3, 4 (Confirmation Dialog, Confirm Button, Cancel Button), chỉ giữ dòng 1 Sign Out Button và đổi cột Description thành `Button that ends the session immediately, without a confirmation dialog.`

## 3.2.5 Change Password

**25. Primary Trigger**
- Hiện tại: `The user opens the Profile screen and clicks the "Đổi mật khẩu" button.`
- Thay bằng:
```
The user opens the Profile screen of the mobile application and clicks "Đổi mật khẩu". The entry is shown only for accounts that sign in with email and password.
```

**26. Interface**
- **Xóa** dòng `Close Button: Closes the form without saving any changes.`
- Hiện tại: `Cancel Button: Button used to close the form without saving changes.`
- Thay bằng:
```
Back Button: App bar button returning to the Profile screen without saving changes.
```
- Hiện tại: `Update Button: Button used to submit the password change request.`
- Thay bằng:
```
Change Password Button: Button used to submit the password change request.
```

**27. Data**
- `New Password: Must contain at least 8 characters and must differ from the current password.` → thay bằng:
```
New Password: Must contain at least 8 characters and must not exceed 72 bytes.
```

**28. Normal Cases**
- Hiện tại: `If the password is updated successfully: The system closes the dialog and refreshes the profile screen.`
- Thay bằng:
```
If the password is updated successfully: The server returns 204 No Content; the application displays "Đã đổi mật khẩu" and returns to the Profile screen.
```
- Hiện tại: `If the user clicks Cancel or Close: The system closes the dialog and discards all unsaved data.`
- Thay bằng:
```
If the user clicks Back: The application returns to the Profile screen and discards all unsaved data.
```

**29. Abnormal Cases**
- Hiện tại: `If the current password is incorrect: The system returns 401 Unauthorized and displays the message "Current password is incorrect."`
- Thay bằng:
```
If the current password is incorrect: The system returns 400 Bad Request and displays the message "Current password is incorrect." A 401 status is deliberately not used, because the client treats 401 as an expired session and signs the user out.
```
- **Xóa** dòng `If the new password is the same as the current password: The system displays the message "New password must be different from the current password."`
- Thêm 1 dòng mới:
```
If the account signs in with Google: The system returns 400 Bad Request with the message "This account signs in with Google and has no password."
```

**30. Table 12. Change Password**
- **Xóa** dòng `2 | Close Button | …`.
- Dòng `Cancel Button | Button | No | No | "Huỷ" | …` → thay bằng: `Back Button | Icon Button | No | No | "←" | App bar button returning to the Profile screen without saving changes.`
- Dòng `Update Button | … | "Cập nhật" | …` → thay bằng: `Change Password Button | Button | No | Yes | "Đổi mật khẩu" | Button used to submit the password change request.`
- Đánh lại số cột # (1–6).
