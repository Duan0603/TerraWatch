# BMAD Architecture Workflow

Gọi kỹ năng `bmad-architecture` để:
- Phân tích và rà soát kiến trúc Microservices của hệ thống.
- Đánh giá tính nhất quán giữa Backend (Core API, AI, GIS), CSDL PostGIS, API Gateway và Event Bus.
- Xuất tài liệu kiến trúc kỹ thuật theo chuẩn C4 Model.
