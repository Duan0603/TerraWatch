# BMAD Code Review Workflow

Kích hoạt quy trình Code Review đa lớp:
- Quét lỗi tiềm ẩn và phân nhánh chưa xử lý (Edge Case Hunter).
- Đối soát mã nguồn với tiêu chuẩn kiến trúc và yêu cầu nghiệp vụ.
- Đưa ra danh sách hành động sửa lỗi cụ thể (Actionable triage).
